# 수학 학습 자료

2025·2026년 고1 6월·9월·10월 문제지와 공식 해설지 12개를 기준으로 180문항을 구성했습니다. 수식의 PDF 문자 인코딩이 깨지므로 원본 문제와 해설을 문항·열 경계로 나눈 PNG로 제공합니다. 긴 해설은 여러 이미지로 이어집니다. 별도로 기출 유형을 참고해 정수 답안형 변형문제 20개를 새로 작성했습니다.

- 공통수학 1: 165문항. 다항식, 방정식과 부등식, 경우의 수, 행렬.
- 공통수학 2: 15문항. 2025년 10월 2·5·11·14·20·21·22·28번, 2026년 10월 2·4·8·12·18·27·29번.
- 집합·명제·함수 단원은 제공 자료에 없어 수록하지 않았습니다.
- 변형문제는 공통수학 1 14문항, 공통수학 2 6문항이며 각 문항에 참고한 기출 번호, 정답, 풀이와 정수 답안 확인 기능을 제공합니다.
- 기출의 풀이 접근 안내는 단원별로 작성한 보조 설명이며, 문항별 상세 해설은 제공된 공식 해설입니다. 자동 채점 대신 공식 풀이와 대조하는 자기 점검 방식입니다.
- 답안·학습 상태는 현재 브라우저의 localStorage에 저장되며 계정 동기화 대상에는 포함하지 않았습니다.
- 웹에서는 한 번 불러온 문제 이미지가 캐시됩니다. 열지 않은 이미지는 오프라인에서 표시되지 않을 수 있습니다. iOS 소스 프로젝트는 전체 math 폴더를 번들에 포함합니다.

재생성: PyMuPDF가 설치된 Python에서 `python3 tools/build_math.py PDF_폴더`를 실행합니다. PDF 파일명은 업로드된 이름(예: `26년 고1 6모 수학.pdf`, `26년 고1 6모 수학 해설.pdf`)을 사용합니다. 자료의 연도 표기는 파일명과 본문 기준입니다.

확인: 전체 180개 번호와 문제/해설 이미지 경로, 모바일 화면의 과목별 개수·해설 이미지 로딩·답안 저장·다시 풀기 필터를 검사했습니다. 이미지 일부는 육안 대조했으나 모든 문항의 수학적 풀이를 독립 재검산한 것은 아닙니다.

## 종합 변형 시험지

공통수학 1·2 각각 텍스트 기반 종합 변형 시험지 1세트(25문항)를 제공합니다. 각 세트는 2점 5개, 3점 15개, 4점 5개로 75점 만점입니다. 일부 문제는 기존 변형문제를 재사용합니다. `python3 tools/build_math_sets.py`로 재생성합니다.

첨부 기출 일부는 아직 텍스트 전사가 완료되지 않아 기존 이미지 방식으로 남아 있습니다. 종합 변형 세트는 기출 원문을 텍스트로 전사한 것이 아닙니다.

## 2026년 6월 텍스트 시험지

2026년 6월 문제지의 객관식 1~21번을 PDF와 공식 해설표를 보고 직접 전사했습니다. 원본 보기 순서와 배점, 공식 정답 번호를 유지하며 도형 2개는 SVG로 다시 그렸습니다. 25문항 구성을 위해 기존 변형문제 4개를 별도로 표시해 추가했습니다. 이 세트의 원본 해설은 공식 해설을 참고해 직접 작성했으며, 원본 단답형 22~30번은 별도 혼합 시험지로 제공하며, 9월 회차의 단답형과 10월 회차의 전사는 아직 완료되지 않았습니다.

전사 데이터는 `math/transcriptions/2026-06-text.json`, 화면에서 읽는 데이터는 `math/transcribed-2026-06.js`이며 `python3 tools/transcribe_2026_06.py`로 재생성합니다.

## 2025년 6월 텍스트 시험지

2025년 6월 객관식 1~21번을 문제지와 공식 정답표에 대조해 전사하고, 변형문제 4문항과 함께 25문항으로 구성했습니다. 조립제법의 주어진 수치는 텍스트로 옮겼고 직육면체와 포물선 그래프는 SVG로 다시 그렸습니다. 생성 스크립트는 `tools/transcribe_2025_06.py`입니다. 단답형 22~30번은 객관식 1~16번과 혼합한 25문항 시험지로 제공합니다. `tools/transcribe_short_2025_06.py`로 재생성합니다.

## 2025년 9월 텍스트 시험지

2025년 9월 객관식 1~21번을 문제지와 공식 정답표에 대조해 전사하고 변형 4문항을 함께 담았습니다. 행렬과 표는 텍스트로 정리했습니다. 생성 스크립트는 `tools/transcribe_2025_09.py`입니다. 단답형 22~30번은 아직 전사하지 않았습니다.

## 2026년 9월 텍스트 시험지

2026년 9월 객관식 1~21번을 전사하여 변형 4문항과 함께 구성했습니다. 도형과 그래프는 SVG로 다시 그렸고 17번과 20번의 경우의 수는 별도로 전수 검증했습니다. 생성 스크립트는 `tools/transcribe_2026_09.py`입니다. 단답형 22~30번은 아직 전사하지 않았습니다.

2026년 6월 단답형 22~30번도 전사하여 기존 객관식 1~16번과 섞은 25문항 시험지로 제공합니다. 단답은 정수를 직접 입력하고 문제지와 답안지에 같은 값이 동기화됩니다. `tools/transcribe_short_2026_06.py`로 재생성합니다.
