# 수학 학습 자료

2025·2026년 고1 6월·9월·10월 문제지와 공식 해설지 12개를 기준으로 180문항을 구성했습니다. 원문 문제는 텍스트와 직접 그린 SVG 도형으로 옮겼으며, 공식 정답을 대조하고 해설을 작성했습니다. 기출 유형을 참고한 변형문제도 제공합니다.

- 공통수학 1: 165문항. 다항식, 방정식과 부등식, 경우의 수, 행렬.
- 공통수학 2: 15문항. 2025년 10월 2·5·11·14·20·21·22·28번, 2026년 10월 2·4·8·12·18·27·29번.
- 첨부 기출에는 집합·명제·함수 문항이 없습니다. 종합 변형 시험지에는 관련 변형문제가 포함됩니다.
- 기출 및 변형문제는 25문항 시험지로 묶어 제공하며, 각 문항에 정답과 풀이가 있습니다.
- 객관식과 정수 단답형을 자동 채점하며 문항별 배점과 해설을 표시합니다.
- 답안·학습 상태는 현재 브라우저의 localStorage에 저장되며 계정 동기화 대상에는 포함하지 않았습니다.
- 텍스트 시험지 데이터는 서비스 워커로 캐시됩니다. iOS 소스 프로젝트는 전체 math 폴더를 번들에 포함합니다.

기존 이미지 자료 재생성: PyMuPDF가 설치된 Python에서 `python3 tools/build_math.py PDF_폴더`를 실행합니다. 텍스트 시험지는 아래 각 생성 스크립트를 사용합니다. 자료의 연도 표기는 파일명과 본문 기준입니다.

확인: 전사한 원문 180개 번호의 누락 여부와 공식 정답, 모바일·PC 화면의 답안 입력과 채점 등을 검사했습니다. 모든 문항의 풀이를 독립적으로 재검산한 것은 아닙니다.

## 종합 변형 시험지

공통수학 1·2 각각 텍스트 기반 종합 변형 시험지 1세트(25문항)를 제공합니다. 각 세트는 2점 5개, 3점 15개, 4점 5개로 75점 만점입니다. 일부 문제는 기존 변형문제를 재사용합니다. `python3 tools/build_math_sets.py`로 재생성합니다.

첨부된 6회차의 180문항은 각 과목의 텍스트 시험지에서 제공하며, 기존 이미지 기반 시험은 목록에서 숨겼습니다. 저장된 학습 기록을 위한 데이터는 유지합니다. 종합 변형 세트는 기출 원문을 텍스트로 전사한 것이 아닙니다.

## 2026년 6월 텍스트 시험지

2026년 6월 문제지의 객관식 1~21번을 PDF와 공식 해설표를 보고 직접 전사했습니다. 원본 보기 순서와 배점, 공식 정답 번호를 유지하며 도형 2개는 SVG로 다시 그렸습니다. 25문항 구성을 위해 기존 변형문제 4개를 별도로 표시해 추가했습니다. 이 세트의 원본 해설은 공식 해설을 참고해 직접 작성했으며, 원본 단답형 22~30번은 별도 혼합 시험지로 제공합니다.

전사 데이터는 `math/transcriptions/2026-06-text.json`, 화면에서 읽는 데이터는 `math/transcribed-2026-06.js`이며 `python3 tools/transcribe_2026_06.py`로 재생성합니다.

## 2025년 6월 텍스트 시험지

2025년 6월 객관식 1~21번을 문제지와 공식 정답표에 대조해 전사하고, 변형문제 4문항과 함께 25문항으로 구성했습니다. 조립제법의 주어진 수치는 텍스트로 옮겼고 직육면체와 포물선 그래프는 SVG로 다시 그렸습니다. 생성 스크립트는 `tools/transcribe_2025_06.py`입니다. 단답형 22~30번은 객관식 1~16번과 혼합한 25문항 시험지로 제공합니다. `tools/transcribe_short_2025_06.py`로 재생성합니다.

## 2025년 9월 텍스트 시험지

2025년 9월 객관식 1~21번을 문제지와 공식 정답표에 대조해 전사하고 변형 4문항을 함께 담았습니다. 행렬과 표는 텍스트로 정리했습니다. 생성 스크립트는 `tools/transcribe_2025_09.py`입니다. 단답형 22~30번은 객관식 1~16번과 혼합해 제공하며, `tools/transcribe_short_2025_09.py`로 재생성합니다.

## 2026년 9월 텍스트 시험지

2026년 9월 객관식 1~21번을 전사하여 변형 4문항과 함께 구성했습니다. 도형과 그래프는 SVG로 다시 그렸고 17번과 20번의 경우의 수는 별도로 전수 검증했습니다. 생성 스크립트는 `tools/transcribe_2026_09.py`입니다. 단답형 22~30번은 객관식 1~16번과 혼합해 제공하며 `tools/transcribe_short_2026_09.py`로 재생성합니다.

2026년 6월 단답형 22~30번도 전사하여 기존 객관식 1~16번과 섞은 25문항 시험지로 제공합니다. 단답은 정수를 직접 입력하고 문제지와 답안지에 같은 값이 동기화됩니다. `tools/transcribe_short_2026_06.py`로 재생성합니다.

## 10월 공통수학 2 텍스트 시험지

2025년 및 2026년 10월의 도형 원문 15문항과 기출 유형 변형 10문항으로 25문항을 구성했습니다. 원문 15문항은 공식 정답과 대조했으며, 그림은 SVG로 다시 그렸습니다. `tools/transcribe_oct_geometry.py`로 재생성합니다. 2026년 10월 공통수학 1 기출도 텍스트로 제공합니다.

## 10월 공통수학 1 텍스트 시험지

2025년 10월 공통수학 1 원문 22문항을 공식 정답표와 대조하여 전사하고 변형 3문항을 더해 25문항 시험지로 구성했습니다. `tools/transcribe_2025_10_algebra.py`로 재생성합니다.

2026년 10월 공통수학 1 원문 23문항을 공식 정답표와 대조해 전사하고 변형 2문항을 더해 25문항 시험지로 구성했습니다. `tools/transcribe_2026_10_algebra.py`로 재생성합니다.

## 현재 시험지 구성

기존 시험지 목록은 새로운 목록으로 교체했습니다. 과목별로 2점·3점·4점 기출을 따로 묶고, 같은 기출을 배점을 섞은 시험지로도 제공합니다. 한 시험지는 최대 25문항이며 마지막 세트도 문항 수를 고르게 나눕니다. 공통수학 2는 첨부 기출이 총 15문항이라 혼합 시험지가 15문항입니다. 기존 기록의 문제 번호를 보존하기 위해 이전 시험지 데이터는 내부에 남겨두었습니다.

변형 문제는 과목별로 새로 작성한 25문항 시험지 2세트씩 제공합니다. `python3 tools/build_math_pools.py`와 `python3 tools/build_math_practice.py`로 재생성합니다.

## 2026년 3월 고2 모의고사

첨부 문제지와 정답·해설을 대조해 30문항을 전사했습니다. 공통수학 1은 16문항, 공통수학 2는 14문항이며, 각 점수별 기출과 혼합 시험지에 기존 문항과 함께 새 세트로 추가했습니다. 기존 진행 기록의 세트 번호를 유지합니다. `python3 tools/transcribe_2026_03_g2.py`로 재생성합니다.
